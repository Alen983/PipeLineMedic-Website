What it is.

PipelineMedic is a GitLab Duo flow for developers. When a CI pipeline fails, it investigates the failure, fixes it on a branch, and opens a merge request with an evidence report. Then it stops. You review and merge. Deploys stay manual.

02 / 04 · About, 2 of 2

What it does.

  • Reads the failing job logs and the code, and reproduces the failure by running the tests
  • Classifies the failure: test, lint, dependency, CI config or security
  • Opens a fix merge request on a fix/pipeline-medic branch with the smallest possible change
  • Writes a report in the MR: root cause with quoted evidence, files changed, confidence, and your next step
  • Treats tests as the spec: it won’t edit tests to go green, and escalates when a test looks wrong
